Connect your cloud
This app works fully offline. To sync records between your devices, connect your own free Supabase project (supabase.com — it's the same service CyTECH uses).
How to get these (1 minute)
  1. Go to supabase.com → sign up free → New project (any name, free plan).
  2. Project Settings → API → copy the Project URL and the anon/public key.
  3. In the SQL Editor, run this once (creates the sync table):
create table if not exists public.cytech_sync ( id uuid primary key default gen_random_uuid(), user_id uuid not null, payload jsonb not null default '{}'::jsonb, updated_at bigint not null default 0 ); alter table public.cytech_sync enable row level security; create policy "own rows" on public.cytech_sync for all using (auth.uid() = user_id) with check (auth.uid() = user_id);

No account needed to use the app — the cloud is optional. You can skip and connect later from Settings.
